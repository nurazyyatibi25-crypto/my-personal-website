IE12103 - Practical Activity 2
Me, My Hometown and Interests website

FILES
- index.html      : Page 1 - Home
- about.html      : Page 2 - About Me
- hometown.html   : Page 3 - My Hometown
- hobbies.html    : Page 4 - Interests & Hobbies
- style.css       : Shared pastel aesthetic design

HOW TO OPEN
1. Extract the ZIP file.
2. Keep all HTML files and style.css in the same folder.
3. Double-click index.html to open the website in a browser.
4. Use the navigation menu to visit all four pages.

IMPORTANT PERSONALISATION BEFORE SUBMISSION
1. In about.html, replace [Your Name] and [Your Age] with your details.
2. Replace the illustrated photo placeholder on About Me with your own picture.
   Suggested method:
   - Create an images folder beside the HTML files.
   - Save your picture as images/my-photo.jpg.
   - Replace the photo-placeholder <div> in about.html with:
     <img src="images/my-photo.jpg" alt="A photo of me"
          style="width:100%;height:390px;object-fit:cover;border-radius:22px;">
3. The Hometown page currently uses illustrative online photos. Replace them with your own
   Semporna photos if possible, or ensure you have permission to use the chosen images.
4. Internet is required for Google Fonts and the online photographs. The website layout and
   text remain available without them, but the online images/fonts may not load offline.

SUBMISSION CHECK
- Test all four pages and every navigation link.
- Take full-page screenshots / print to PDF for each separate page:
  homepage.pdf, aboutyou.pdf, hometown.pdf, hobbies.pdf.
- Submit the published website link and upload the four PDFs separately to iTeL.
